About TypeDle

TypeDle is a small daily puzzle game built for fans of Pokémon and Wordle-style guessing games. Instead of letters, you're working with type matchups: weaknesses, resistances, and immunities, alongside a Pokémon's evolution stage, home region, and ability. It's a project built and maintained by one person as a hobby, and shared publicly for anyone to play for free.

How it's built

TypeDle is a React and TypeScript web app with a small backend that tracks global stats and optional player accounts. The daily puzzle, type-effectiveness math, and clue reveals all run client-side; the backend only stores streaks, guess history, and aggregate stats for players who choose to create an account.

Data sources and credits

The Pokémon roster, artwork, and reference data used in TypeDle come from a few community sources:

  • Bulbagarden: type icon archive
  • PokeAPI: roster data, evolution chains, and renders
  • Serebii: Legends: Z-A Mega roster reference
  • Pokémon DB: fallback artwork
